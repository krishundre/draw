# Libraries

The **Library** panel (📚 icon, top-right) is where reusable shapes live — a small built-in set, plus anything you save yourself.

## Using a library shape

Open the Library panel and click any shape to drop a copy of it onto the canvas.

## Saving your own shapes

1. Select one or more elements on the canvas (e.g. a styled box with a text label — anything you'd like to reuse).
2. Open the Library panel and click **+ Add selection**.
3. Give it a name. It now appears under **My library** and is saved in your browser for next time.

## Removing a saved shape

Click the small ✕ on a "My library" item to remove it.

## Importing / exporting a library file

Your custom library can be exported as a `.excalidrawlib` file (a JSON file) and imported again later — on this device or a different one:

- **Export** — click **Export** in the Library panel to download a `.excalidrawlib` file with everything in "My library."
- **Import** — click **Import** and choose a `.excalidrawlib` file (yours, or one someone shared with you) to add its shapes to your library.
