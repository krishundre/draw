# Libraries

The **Library** panel (📚 icon, top-right) is where reusable shapes live, as a docked sidebar with three tabs:

- **Built-in** — DrawBoard's starter shapes, including a ready-made "Flowchart: decision" preset (a decision diamond with two bound, elbow-routed branches) you can drop on the canvas and adapt.
- **My library** — anything you've saved yourself.
- **Imported** — shapes brought in from a `.excalidrawlib` file, kept separate from what you added by hand so you can tell them apart.

## Using a library shape

Open the Library panel, pick a tab, and click any shape to drop a copy of it onto the canvas.

## Saving your own shapes

1. Select one or more elements on the canvas (e.g. a styled box with a text label — anything you'd like to reuse).
2. Open the Library panel and click **+ Add selection**.
3. Give it a name. It now appears under the **My library** tab and is saved in your browser for next time.

## Removing a saved shape

Switch to the **My library** or **Imported** tab and click the small ✕ on an item to remove it.

## Importing / exporting a library file

Your custom library can be exported as a `.excalidrawlib` file (a JSON file) and imported again later — on this device or a different one:

- **Export** — click **Export** in the Library panel to download a `.excalidrawlib` file with everything you've saved.
- **Import** — click **Import** and choose a `.excalidrawlib` file (yours, or one someone shared with you) — its shapes land in the **Imported** tab.
