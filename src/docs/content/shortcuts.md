# Keyboard Shortcuts

## Tools

| Shortcut | Action |
|---|---|
| `V` / `1` | Selection tool |
| `R` / `2` | Rectangle |
| `D` / `3` | Diamond |
| `O` / `4` | Ellipse |
| `A` / `5` | Arrow |
| `L` / `6` | Line |
| `P` / `7` | Draw (freehand) |
| `T` / `8` | Text |
| `9` | Insert image |
| `E` / `0` | Eraser |
| `F` | Frame |
| `H` / hold `Space` + drag | Hand (pan) |

## Editing

| Shortcut | Action |
|---|---|
| `Ctrl`/`Cmd` + `Z` | Undo |
| `Ctrl`/`Cmd` + `Shift` + `Z` (or `Ctrl`/`Cmd` + `Y`) | Redo |
| `Ctrl`/`Cmd` + `D` | Duplicate selection |
| `Ctrl`/`Cmd` + `G` | Group selection |
| `Ctrl`/`Cmd` + `Shift` + `G` | Ungroup selection |
| `Ctrl`/`Cmd` + `A` | Select all |
| `Delete` / `Backspace` | Delete selection |
| Arrow keys | Nudge selection by 1px |
| `Shift` + arrow keys | Nudge selection by 10px |

## View & navigation

| Shortcut | Action |
|---|---|
| `Ctrl`/`Cmd` + scroll | Zoom in/out (centered on cursor) |
| Scroll / two-finger swipe | Pan |

## Other

| Shortcut | Action |
|---|---|
| `Ctrl`/`Cmd` + `K` | Open the command palette |
| `Shift` + `/` (i.e. `?`) | Open this shortcut help dialog in the app |
| `Escape` | Deselect / close open dialogs |
| Right-click | Open the context menu |

This same list is available inside the app any time — click the **?** icon (top-right) or press `Shift` + `/`.
