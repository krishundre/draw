# Keyboard Shortcuts

## Tools

| Shortcut | Action |
|---|---|
| `V` / `1` | Selection tool |
| `Q` | Lasso (freeform) selection |
| `R` / `2` | Rectangle |
| `D` / `3` | Diamond |
| `O` / `4` | Ellipse |
| `A` / `5` | Arrow |
| `L` / `6` | Line |
| `P` / `7` | Draw (freehand) |
| `T` / `8` | Text |
| `9` | Insert image |
| `W` | Embed a web page |
| `E` / `0` | Eraser |
| `F` | Frame |
| `H` / hold `Space` + drag | Hand (pan) |

## Multi-point lines & arrows

| Shortcut | Action |
|---|---|
| Click, click, click… (Line/Arrow tool) | Place each point of a multi-point line/arrow |
| `Enter`, or click near the last point | Finish the multi-point chain |
| `Escape` | Cancel the chain in progress |
| Double-click an existing line/arrow | Enter point-edit mode |
| Click a segment (in point-edit mode) | Insert a new point there |
| `Alt` + click a point (in point-edit mode) | Remove that point |
| `+` / `=` (in point-edit mode) | Add a point at the first segment's midpoint |
| `Alt` + `Backspace` (in point-edit mode) | Remove the last point |

## Editing

| Shortcut | Action |
|---|---|
| `Ctrl`/`Cmd` + `Z` | Undo |
| `Ctrl`/`Cmd` + `Shift` + `Z` (or `Ctrl`/`Cmd` + `Y`) | Redo |
| `Ctrl`/`Cmd` + `C` / `V` | Copy / paste (system clipboard) |
| `Ctrl`/`Cmd` + `D` | Duplicate selection |
| `Ctrl`/`Cmd` + `G` | Group selection |
| `Ctrl`/`Cmd` + `Shift` + `G` | Ungroup selection |
| `Ctrl`/`Cmd` + `A` | Select all |
| `Delete` / `Backspace` | Delete selection |
| Arrow keys | Nudge selection by 1px |
| `Shift` + arrow keys | Nudge selection by 10px |
| `Ctrl`/`Cmd` + click a linked element | Open its link |

## View & navigation

| Shortcut | Action |
|---|---|
| `Ctrl`/`Cmd` + scroll | Zoom in/out (centered on cursor) |
| Scroll / two-finger swipe | Pan |
| `Ctrl`/`Cmd` + `Shift` + `F` | Search elements by text or type |

## Other

| Shortcut | Action |
|---|---|
| `Ctrl`/`Cmd` + `K` | Open the command palette |
| `Shift` + `/` (i.e. `?`) | Open this shortcut help dialog in the app |
| `Escape` | Deselect / close open dialogs / exit point-edit, crop, or embed-interact mode |
| Right-click | Open the context menu |

This same list is available inside the app any time — click the **?** icon (top-right) or press `Shift` + `/`.
